# Reprodukálható tesztbetűtípus

DejaVu Sans, a Debian fonts-dejavu-core csomagból, változtatás nélkül.
Forrás: https://dejavu-fonts.github.io/ . Licenc: DejaVu-LICENSE.txt.
A font kizárólag a szintetikus teszt-PDF-ek előállításához kell; nem része az EXE-nek.
A Windows Arial PDF-be ágyazásakor a glyph-visszafejtés szóköz helyett NBSP-t,
kötőjel helyett lágy elválasztást adott. Azonos fonttal mindkét platformon ugyanazt
a referenciaszöveget vizsgáljuk, az eredeti szigorú ellenőrzések megtartásával.
